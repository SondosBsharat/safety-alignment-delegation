# Third-party source and benchmark

`vendor/masdrift/` is an unmodified source snapshot from
https://github.com/ZhuoningXu/MasDrift at commit
`7119c09c0266162f89db29d3faa32d496837b5c3`.

Copyright (c) 2026 MasDrift contributors. The complete upstream MIT license is
included at [vendor/masdrift/LICENSE](vendor/masdrift/LICENSE). The upstream
README and citation are preserved. `configs/upstream_files.sha256.json` records
the SHA-256 of every file in the snapshot.

The benchmark scenarios and simulated tool environments are provided by
MasDrift. The selected task IDs, pilot traces, evaluation outputs, and figures
in this project's top-level folders document this project's use of that
benchmark. Top-level scripts provide reproduction and summary utilities;
they do not replace the upstream agent or evaluator implementation.
