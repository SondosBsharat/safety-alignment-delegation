# Third-Party Code and Attribution

This project builds on [MasDrift](https://arxiv.org/abs/2608.07556). The original source code, benchmark, and evaluation tools are included in `vendor/masdrift/`, together with the upstream README and license.

The benchmark tasks and simulated environments come from MasDrift. Our project includes the selected tasks, preliminary execution traces, evaluation results, figures, and scripts for reproducing the reported measurements.

The original MasDrift implementation has not been modified. File hashes are recorded in `configs/upstream_files.sha256.json` to help verify the included source files.
